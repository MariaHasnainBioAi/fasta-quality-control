# FASTA Quality Control and Sequence Report 🧬

## Project Overview
This beginner-friendly bioinformatics project uses Python and Biopython to perform basic quality control of DNA sequences in FASTA format.

## Features
- Reads DNA sequences from a FASTA file.
- Calculates sequence length.
- Calculates GC content percentage.
- Identifies unexpected characters in DNA sequences.
- Reports whether each sequence is valid or invalid.
- Exports results to a CSV report.

## Tools and Technologies
- Python
- Biopython
- CSV

## Project Files
- `FASTA QUALITY REPORT.py` — Main Python script.
- `sample_data.fasta` — Sample DNA sequences used for testing.
- `sequence_report.csv` — Generated quality control report.

## Learning Objectives
This project demonstrates basic Python programming, DNA sequence analysis, data validation and structured reporting for bioinformatics.
